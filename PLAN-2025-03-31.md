# Turbo Language — Plan (March 31, 2025)

## Immediate: Codebase Restructuring

Monster single-file crates need splitting into modules:

### turbo-sema (5,054 lines → ~5 files)
```
src/
  lib.rs          — public API (check function)
  types.rs        — Ty enum, Display, resolution
  checker.rs      — Checker struct, scope management
  expr.rs         — check_expr (biggest chunk)
  builtins.rs     — builtin function type checking (~500 lines)
```

### turbo-codegen-cranelift (5,884 lines → ~6 files)
```
src/
  lib.rs          — public API (jit_run, aot_compile)
  compile_expr.rs — expression compilation
  compile_stmt.rs — statement compilation
  builtins.rs     — print, map, filter, reduce, HTTP, JSON
  runtime.rs      — runtime function declarations + Rust JIT impls
  control_flow.rs — if/else, while, for-in, match, break/continue
```

### turbo-codegen-llvm (3,433 lines → ~4 files)
```
src/
  lib.rs          — public API (aot_compile)
  compile.rs      — expression + statement compilation
  builtins.rs     — builtin compilation
  runtime.rs      — runtime function declarations
```

### turbo-cli (2,168 lines → already split, but cleanup)
```
src/
  main.rs         — CLI entry point + command dispatch
  runner.rs       — run/build logic
  formatter.rs    — turbolang fmt (already separate)
  repl.rs         — turbolang repl (already separate)
  test_runner.rs  — turbolang test logic
  doc_gen.rs      — turbolang doc logic
```

## Shared Codegen Interface

Both backends should implement a trait:
```rust
pub trait TurboCodegen {
    fn aot_compile(module: &turbo_ast::Module, output: &Path) -> Result<(), CodegenError>;
}
```

## LLVM Backend: Finish Missing Features

71/96 tests pass. Missing:
- Closures (need function pointer + env struct, same pattern as Cranelift)
- spawn/async (compile as sync wrapper, same as Cranelift)
- map/filter/reduce (need call_indirect for closure function pointers)
- @derive macros (compile-time code generation)
- Default trait methods (synthesize method bodies)
- @unsafe + deref/store
