Pattern Matching & Pipes

Pattern Matching
fn area(shape: Shape) -> f64 {
  match shape {
    Circle(r) => PI * r * r
    Rectangle(w, h) => w * h
    Triangle(a, b, c) => {
      let s = (a + b + c) / 2.0
      sqrt(s * (s-a) * (s-b) * (s-c))
    }
  }
}

Structured Concurrency

Concurrent Fetch
// Like Promise.all, but with structured scoping
async fn fetch_all(urls: [str]) -> [Data] ! Error {
  scope (s) => {
    let tasks = urls.map((url) =>
      s.spawn(async { await fetch(url)? })
    )
    await tasks.collect()?
  }
}
Channels & Select

spawn async {

Memory Model

The Escape Hatches Ladder

Start writing code like JavaScript. The compiler manages memory for you. Only opt into complexity when your profiler says you need it.

Level 0

Just Write Code

Auto-clone, auto-manage. No memory annotations. The compiler handles everything — identical DX to JavaScript.

For: Web devs, scripting, prototyping

// Pure JavaScript-style Turbo. No annotations.
fn handle_request(req: Request) -> Response {
  let user = await auth.verify(req.token)
  let data = await db.query(
    "SELECT * FROM posts WHERE author = ?",
    user.id
  )
  let html = template.render("posts.html",
    { user: user, posts: data }
  )
  Response.ok(html)
}
// Everything freed automatically at scope end.

Level 1

Explicit Borrows

Use let ref for zero-copy access when you know a value is large and you only need to read it. One keyword, big savings.

For: Performance-aware app devs

fn analyze(dataset: [Record]) -> Summary {
  let ref first = dataset[0]
  let ref last  = dataset[dataset.len() - 1]

  print("Range: {first.date} to {last.date}")
  compute_summary(dataset)
}
// Zero-copy reads. No cloning 10GB datasets.

Level 2

Region Blocks

Batch allocations that live and die together. One pointer reset frees everything. Ideal for request handling, per-frame game logic, compilation passes.

For: Server devs, game devs

fn render_frame(world: &World) -> FrameBuffer {
  region frame {
    let visible  = cull(world.entities, world.camera)
    let sorted   = depth_sort(visible)
    let commands = generate_draw_calls(sorted)
    execute_commands(commands)
  }
  // All temporaries freed in one O(1) reset.
}

Level 3

Manual Control

Full control over every byte. Explicit alloc/free with defer. Strict ownership checking — like Rust, but opt-in.

For: Engine devs, embedded, kernel, FFI

@manual
fn process_audio(input: &[f32], output: &mut [f32]) {
  let scratch = alloc<f32>(input.len())
  defer free(scratch)

  dsp.filter(input, scratch)
  dsp.normalize(scratch, output)
}
// You control every allocation. The compiler enforces safety.

Toolchain

One CLI. Everything Included.

No separate installs for formatting, linting, testing, or benchmarking. The turbo CLI ships everything as a unified experience.

turbo build

Compile to a native binary via LLVM. Supports cross-compilation, WASM, and release profiles. Incremental by default.

turbo run

Build and execute in one step. Hot-reload in dev mode. Top-level await works out of the box — great for scripts.

turbo test

Built-in test runner with @test attribute. Parallel execution, snapshot testing, and coverage reports.

turbo fmt

Opinionated formatter. Zero config. Consistent style across every Turbo codebase, enforced automatically.

turbo bench

Micro-benchmarking with statistical analysis. Use @bench to mark benchmarks. Reports p50, p99, and throughput.

turbo profile

Built-in CPU and memory profiler. Attach to running processes. Generates flame graphs and allocation timelines.

turbo doc

Generate browseable documentation from doc comments. Includes type signatures, examples, and cross-references.

turbo add

Built-in package manager. Add dependencies, resolve versions, and lock files. No separate tooling required.

Roadmap

Growing With You

Progressive disclosure — start simple, unlock power as you need it.

v1.0

Core Language

Native + WASM compilation, typed async, full toolchain, and a small core the authors are willing to freeze. Everything you need to build production software from day one — without compiler-level framework lock-in.

v1.1

Script Mode

Zero-config single-file execution. Write a .turbo file, run it directly — no project setup, no boilerplate. Perfect for scripting and automation.

v1.2

GPU Compute

@gpu kernels, turbo/tensor library, and SIMD intrinsics. Write GPU shaders and compute kernels in pure Turbo — no separate shader language.

v1.3

Mobile

iOS and Android compilation targets with cross-platform UI primitives. Build native mobile apps with the same language and toolchain.

v1.4

Distributed

Cluster actors, service mesh integration, and distributed tracing. Scale from a single binary to a fleet of services without changing your programming model.
