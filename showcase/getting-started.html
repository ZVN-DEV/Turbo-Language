Getting Started

Go from zero to running Turbo code in under five minutes. Install the toolchain, create a project, and explore the language through five progressive examples.

Step 1

Installation

Turbo ships as a single binary with everything included: compiler, formatter, linter, test runner, package manager, REPL, and LSP. One install, zero additional setup.

Turbo v0.5.0 is available now — install via Homebrew or the source build below.

Terminal
# macOS
brew install turbo-lang

# Linux
curl -fsSL https://turbo-lang.dev/install.sh | sh

# Windows
winget install turbo-lang

# Or from source
git clone https://github.com/turbo-lang/turbo
cd turbo && turbo build --release

Verify the installation:

Terminal
$ turbo --version
turbo 0.1.0 (aarch64-apple-darwin)
Includes: compiler, lsp, fmt, test, bench, doc, repl, pkg
Step 2

Your First Program

Create a file called hello.tb and run it. No boilerplate, no config, no build step.

hello.tb
// hello.tb
fn main() {
  print("Hello, Turbo!")
}
Terminal
$ turbo run hello.tb
Hello, Turbo!

That is it. The turbo run command compiles and executes in a single step. For development, add --watch to auto-rebuild on changes.

Step 3

Create a Project

Use turbo new to scaffold a full project with configuration, source directory, and tests already wired up.

Terminal
$ turbo new my-app
$ cd my-app
$ turbo run

This generates the following project structure:

my-app/
  turbo.toml
  src/
    main.tb
  tests/
    main_test.tb

The turbo.toml file holds your project metadata, dependencies, and build configuration:

turbo.toml
[package]
name = "my-app"
version = "0.1.0"
edition = "2026"

[dependencies]
# Add deps with: turbo add <package>

[build]
target = "native"
Step 4

Quick Tour

Five examples that take you from familiar basics to Turbo's most powerful features. Each builds on the last.

1. Variables and Functions

Turbo uses let for immutable bindings and let mut for mutable ones. Types are inferred, but you can annotate when it adds clarity. String interpolation uses {} inside double quotes. The last expression in a function is the return value.

Turbo
let name = "World"
let mut count = 0

fn greet(who: str) -> str {
  count += 1
  "Hello, {who}! (greeted {count} times)"
}

2. Types and Pattern Matching

Define algebraic data types with the type keyword. Each variant can carry data. The match expression is exhaustive — the compiler ensures you handle every case.

Turbo
type Shape {
  Circle(radius: f64)
  Rectangle(width: f64, height: f64)
}

fn area(s: Shape) -> f64 {
  match s {
    Circle(r) => 3.14159 * r * r
    Rectangle(w, h) => w * h
  }
}

3. Error Handling

Functions that can fail use the T ! E result syntax. The ? operator propagates errors to the caller automatically. Optionals use T? with none (lowercase) for the absent case.

Turbo
fn read_config(path: str) -> Config ! IoError {
  let text = await fs.read(path)?
  let config = parse_toml(text)?
  config
}

// Usage — errors propagate with ?
let config = read_config("config.toml")?

4. Async and Concurrency

Turbo's async model feels like JavaScript — async/await, all() for concurrent execution, and for await for streaming. Under the hood, tasks are lightweight (not OS threads) and scheduled by a work-stealing runtime.

Turbo
let [users, posts] = await all([
  fetch_users(),
  fetch_posts()
])

for await event in stream {
  print("Got: {event}")
}

5. HTTP + JSON In One File

Turbo ships an HTTP server, routing, and JSON helpers as built-ins. You can serve a typed JSON API in a single file with no framework, no external dependency, and the same compiler you used for your first hello-world.

Turbo
fn main() {
  let app = http_server(8080)

  route(app, "GET", "/health", |req: str| -> str {
    respond_text(200, "ok")
  })

  http_listen(app)
}
