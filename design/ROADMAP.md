# Superseded roadmap sketch

This file used to contain a broad v1.x design-vision roadmap covering GPU,
mobile, distributed systems, UI syntax, and advanced runtime features. That
roadmap predated the current release-closeout work and mixed aspirational syntax
with shipped capabilities.

The canonical public roadmap is now [docs/ROADMAP.md](../docs/ROADMAP.md).
Use that document for release planning, public claims, and status language.

Historical design sketches remain useful only as background for future design
discussion. They are not product commitments, release promises, or evidence that
a feature exists in the compiler today.
