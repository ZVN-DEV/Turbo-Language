What This Measures

Benchmark Details

  • Recursive Fibonacci(40) — 204,668,309 function calls, pure recursion with no memoization. This stress-tests function call overhead, stack management, and basic integer arithmetic.
  • Turbo appears in two tiers. turbo build (Cranelift AOT) produces a native binary — measured the same way as C, Rust, and Swift. turbo run (Cranelift JIT) compiles and executes in one step — the 400ms includes compilation time.
  • Both modes use the same Cranelift code generator, so generated code quality is identical. AOT adds PIC overhead; JIT includes compilation time. The two roughly cancel out.
  • Compiled languages used -O2 or equivalent flags. JIT runtimes include startup and warmup time in the measurement.
  • All tests run 3+ times, median reported. Platform: Apple Silicon M-series, Darwin arm64, macOS.
  • This is a single-threaded, CPU-bound microbenchmark. Real-world performance depends on many factors including I/O, memory allocation patterns, and concurrency.

Data collected February 23, 2026. Platform: Apple Silicon M-series, macOS (Darwin arm64).
