# E0120 — Try operator requires Result type

## What it means
The `?` (try) operator can only be applied to values of Result type
(`T ! E`). Using it on other types is a type error.

## Example
```turbo
fn main() {
    let x: i64 = 5
    let y = x?  // x is not a Result
}
```

## How to fix
Ensure the expression the `?` is applied to returns a Result. If you
just want to propagate `None` from an optional, use a pattern match.
