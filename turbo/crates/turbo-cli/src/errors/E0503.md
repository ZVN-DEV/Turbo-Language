# E0503 — Cannot assign to immutable index

## What it means
Array-element assignment (`arr[i] = expr`) requires the array to be
bound mutably.

## Example
```turbo
fn main() {
    let xs = [1, 2, 3]
    xs[0] = 9  // xs is immutable
}
```

## How to fix
Declare the array with `let mut`: `let mut xs = [1, 2, 3]`.
