# E0525 — HashMap key type must be int or str

## What it means
A `HashMap<K, V>` was declared (or used) with a key type `K` that the
compiler cannot hash and compare. In this version, hash-map keys are
restricted to `int` (any integer type, hashed by identity) and `str`
(hashed by contents). Struct, array, enum, tuple, function, and other
compound key types are not yet supported.

Values (`V`) have no such restriction — any type may be a value, including
`str`, arrays, structs, enums, `Result`/`Optional`, and function values.

## Example
```turbo
struct Point { x: i64, y: i64 }

fn main() {
    let m: HashMap<Point, str> = hashmap()   // error: key type is a struct
    print(hashmap_len(m))
}
```

## How to fix
- Use `int` or `str` as the key type:
  ```turbo
  let by_id: HashMap<int, str> = hashmap()
  let by_name: HashMap<str, Point> = hashmap()
  ```
- If you need to key by a compound value, derive a stable `int` or `str`
  key from it yourself (for example, format the struct into a string, or
  use a numeric id field) and use that as the map key.
