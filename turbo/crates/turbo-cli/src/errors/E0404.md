# E0404 — Linker/build error

## What it means
Codegen produced an object file, but the system linker (`cc`) failed
to produce a final binary. Common causes include missing system
libraries, incompatible object formats, or platform-specific linker
issues.

## How to fix
Check the error output for the underlying `cc`/`ld` message. Ensure a
working C compiler toolchain is installed (`xcode-select --install` on
macOS, `build-essential` on Debian/Ubuntu).
