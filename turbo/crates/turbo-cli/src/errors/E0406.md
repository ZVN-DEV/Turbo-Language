# E0406 — Missing function definition

## What it means
Codegen was asked to lower a call to a function whose body it couldn't
find. This can happen with declared-but-not-defined functions or
internal bookkeeping bugs.

## How to fix
Ensure the function is defined (not just declared), and check that
its name matches at the call site. If the issue persists with a
defined function, please file an issue.
