# E0322 — Function in agent is not a tool fn

## What it means
A function listed in an agent's `tools:` must be marked `tool fn`.
Regular `fn` functions aren't exposed to the agent runtime.

## Example
```turbo
fn do_thing() { }
agent Bot { tools: [do_thing] }  // must be tool fn
```

## How to fix
Change the function to `tool fn do_thing() { }`.
