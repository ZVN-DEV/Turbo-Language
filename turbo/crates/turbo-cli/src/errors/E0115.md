# E0115 — Cannot infer type of empty array literal

## What it means
An empty array literal `[]` has no elements to infer its element type
from, and no type annotation was provided.

## Example
```turbo
fn main() {
    let xs = []  // cannot infer element type
}
```

## How to fix
Add a type annotation: `let xs: [i64] = []`, or push an element with the
desired type first.
