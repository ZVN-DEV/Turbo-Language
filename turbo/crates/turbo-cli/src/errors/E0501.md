# E0501 — Cannot assign to immutable variable

## What it means
The variable was declared with `let` (immutable by default). Only
variables declared with `let mut` may be reassigned.

## Example
```turbo
fn main() {
    let x = 1
    x = 2  // x is immutable
}
```

## How to fix
Declare the variable as mutable: `let mut x = 1`.
