# E0202 — Match guard must be bool

## What it means
A pattern guard `if <expr>` in a match arm must be a boolean expression.

## Example
```turbo
fn main() {
    let x = 5
    match x {
        n if "yes" => print("ok")  // str is not bool
        _ => print("no")
    }
}
```

## How to fix
Use a boolean expression in the guard, e.g. `n if n > 0 =>`.
