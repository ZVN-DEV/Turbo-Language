# E0305 — Unknown type

## What it means
A type name was used in a type annotation or signature, but the name
doesn't refer to any primitive, struct, enum, alias, or generic
parameter in scope.

## Example
```turbo
fn main() {
    let x: Widget = new_widget()  // Widget not defined
}
```

## How to fix
Check for typos, import the type, or define it. Primitive types
include `i8..i64`, `u8..u64`, `f32`, `f64`, `bool`, `str`, `int`,
`float`.
