# E0111 — Cannot assign incompatible type to variable

## What it means
An assignment (`x = expr`) attempted to store a value whose type doesn't
match the variable's declared type.

## Example
```turbo
fn main() {
    let mut x = 1
    x = "hi"  // x was inferred as int
}
```

## How to fix
Assign a value whose type matches the variable. If you need a different
type, introduce a new binding with `let`.
