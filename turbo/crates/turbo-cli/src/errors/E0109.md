# E0109 — Function return type mismatch

## What it means
The function's declared return type does not match the type of its body
(or the type of an explicit `return` expression).

## Example
```turbo
fn greet() -> str {
    42  // declared str, body returns int
}
```

## How to fix
Either adjust the function's declared return type or return a value of
the declared type. Remember that the tail expression of the body is the
return value; if the body ends in a statement, the return is `()`.
