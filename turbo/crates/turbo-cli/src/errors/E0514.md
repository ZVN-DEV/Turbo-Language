# E0514 — Unused return value of pure function

## What it means
A pure function (one that has no side effects) was called and its
return value was discarded. Since the function does nothing else,
ignoring the result means the call was wasted.

## Example
```turbo
fn square(n: i64) -> i64 { n * n }
fn main() {
    square(5)  // return value discarded
}
```

## How to fix
Either use the result (`let y = square(5)`) or remove the call.
