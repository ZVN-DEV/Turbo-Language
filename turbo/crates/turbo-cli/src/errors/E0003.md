# E0003 — Maximum nesting depth exceeded (legacy)

## What it means
Historically reported by the parser when an expression or block was
nested too deeply. As of v0.7.7 the shared parser+codegen recursion
limit is reported under [`E0516`](E0516.md) instead. This code is
retained only so old error logs remain resolvable.

## How to fix
See [`E0516`](E0516.md).
