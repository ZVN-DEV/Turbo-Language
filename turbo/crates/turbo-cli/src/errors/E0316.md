# E0316 — Enum has no variant

## What it means
A reference to `EnumName::Variant` used a variant name that isn't
defined on the enum.

## Example
```turbo
enum Color { Red, Green, Blue }
fn main() {
    let c = Color::Yellow  // no Yellow variant
}
```

## How to fix
Check the enum definition for the correct variant name, or add the
variant.
