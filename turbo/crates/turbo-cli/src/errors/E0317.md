# E0317 — No method found on type

## What it means
A method call with dot syntax (`x.foo()`) named a method that isn't
defined in any `impl` block for the receiver's type.

## Example
```turbo
struct Point { x: i64, y: i64 }
impl Point { fn area(&self) -> i64 { 0 } }
fn main() {
    let p = Point { x: 1, y: 2 }
    p.volume()  // not defined
}
```

## How to fix
Check for typos. Implement the method if it should exist, or use an
existing method with the correct name.
