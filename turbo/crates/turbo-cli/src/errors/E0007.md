# E0007 — Invalid attribute

## What it means
An `@attribute` was used incorrectly: either the attribute name is
unrecognized, or it was attached to an item that does not accept it.

## Example
```turbo
@wat
fn main() { }
```

## How to fix
Check the list of supported attributes: `@test`, `@unsafe`, `@derive(...)`,
`@inline`, etc. Remove or replace the offending attribute.
