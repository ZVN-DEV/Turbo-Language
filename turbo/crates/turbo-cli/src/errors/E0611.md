# E0611 — Source file not found or could not be read

## What it means
The compiler was asked to run or build a source file it could not open.
Usually the path does not exist; it may also point at a directory or at a
file the current user lacks permission to read.

## Example
```console
$ turbolang run nope.tb
error[E0611]: could not find `nope.tb` — check the path
```

## How to fix
- Confirm the file exists and the path is spelled correctly (paths are
  relative to your current working directory).
- If the path contains a directory, make sure each segment exists.
- On a permission error, check the file's mode or run as a user that can
  read it.
