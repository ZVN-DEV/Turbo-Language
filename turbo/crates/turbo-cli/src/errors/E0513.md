# E0513 — Builtin argument count error

## What it means
A builtin function was called with the wrong number of arguments. For
example, calling `len()` with zero args or `push(x)` with only one
arg.

## Example
```turbo
fn main() {
    let n = len()  // needs 1 argument
}
```

## How to fix
Check the builtin's signature and supply the correct number of
arguments.
