# E0319 — Unknown derive trait

## What it means
A `derive(...)` clause named a trait that Turbo's compiler doesn't know
how to auto-implement.

## Example
```turbo
struct Point derive(Foo) { x: i64, y: i64 }
```

## How to fix
Use one of the supported derives (`Eq`, `Hash`, `Clone`, `Debug`, etc.)
or implement the trait manually.
