# E0131 — Type parameter inference conflict

## What it means
A single generic type parameter was inferred to be two different
concrete types in the same call, which is impossible.

## Example
```turbo
fn pair<T>(a: T, b: T) -> T { a }
fn main() {
    let x = pair(1, "two")  // T inferred as both i64 and str
}
```

## How to fix
Ensure all arguments that share a type parameter have the same type, or
explicitly specify the type parameter at the call site.
