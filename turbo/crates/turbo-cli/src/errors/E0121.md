# E0121 — Try operator in non-Result function

## What it means
The `?` operator propagates errors by early-returning from the enclosing
function. That function's return type therefore must also be a Result
with a compatible error type.

## Example
```turbo
fn parse_num(s: str) -> i64 ! str { ... }

fn main() {
    let x = parse_num("42")?  // main returns unit, not a Result
}
```

## How to fix
Change the enclosing function's signature to return a Result, or handle
the error inline with a match.
