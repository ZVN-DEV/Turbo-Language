# E0124 — Cannot index into non-array type

## What it means
The index operator `[]` is only valid on array (and hashmap-by-key)
types. Applying it to integers, booleans, or structs is a type error.

## Example
```turbo
fn main() {
    let x: i64 = 5
    let y = x[0]  // i64 is not indexable
}
```

## How to fix
Only index into arrays. For struct field access, use the dot operator:
`obj.field`.
