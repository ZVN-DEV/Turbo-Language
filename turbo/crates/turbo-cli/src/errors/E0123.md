# E0123 — Array index must be integer

## What it means
Array indexing (`arr[i]`) requires the index expression to have an
integer type. Strings, booleans, and floats are not valid indices.

## Example
```turbo
fn main() {
    let xs = [1, 2, 3]
    let x = xs["0"]  // str is not an int
}
```

## How to fix
Use an integer literal or integer variable as the index.
