# E0133 — Builtin function argument type mismatch

## What it means
A builtin function (like `len`, `push`, `sqrt`, `upper`) was called with
an argument whose type doesn't match its expected signature.

## Example
```turbo
fn main() {
    let n = len(42)  // len expects array/str, got i64
}
```

## How to fix
Check the builtin's expected argument types and pass a compatible
value. Use `turbolang explain` with the specific error code shown to
confirm the expected types.
