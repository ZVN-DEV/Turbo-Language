# E0113 — Cannot assign incompatible type to array element

## What it means
Array element assignment (`arr[i] = expr`) used a value whose type
doesn't match the array's element type.

## Example
```turbo
fn main() {
    let mut xs = [1, 2, 3]
    xs[0] = "hi"  // xs is [int]
}
```

## How to fix
Store a value of the correct element type.
