# E0100 — Type mismatch

## What it means
Two types were expected to match but they differ. This is the most common
type error and shows up in return-type checks, argument checks, and
several other places.

## Example
```turbo
fn greet() -> str {
    42  // expected str, found int
}
```

## How to fix
Ensure the value's type matches the expected type. Use `to_str()` for
string conversions, or adjust the function signature / type annotation.
