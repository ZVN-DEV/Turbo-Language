# E0136 — Expression nesting too deep

## What it means
An expression is nested more deeply than the semantic analyzer allows.
This protects against runaway recursion in pathological source files.

## Example
A chain of thousands of parenthesized subexpressions, or generated code
with absurdly deep call trees.

## How to fix
Refactor the expression into smaller helper bindings or functions. If
you believe the limit is too strict, please file an issue with a
reproduction.
