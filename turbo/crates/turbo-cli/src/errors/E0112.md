# E0112 — Cannot assign incompatible type to struct field

## What it means
An assignment to a struct field (`obj.field = expr`) used a value whose
type doesn't match the field's declared type.

## Example
```turbo
struct Point { x: i64, y: i64 }
fn main() {
    let mut p = Point { x: 1, y: 2 }
    p.x = "zero"  // x is i64
}
```

## How to fix
Assign a value of the correct type, or rethink the field's type.
