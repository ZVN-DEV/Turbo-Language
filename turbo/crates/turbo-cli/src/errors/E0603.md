# E0603 — Integer overflow at runtime

## What it means
An integer operation produced a result that does not fit in a 64-bit
signed integer (`i64`, the type behind `int`). Rather than silently
wrapping around to a wrong value, the program traps and exits.

The classic case is `i64::MIN / -1`: the mathematically correct result
(`9223372036854775808`) is one past the largest representable `i64`.

## Example
```turbo
fn main() {
    let x: i64 = -9223372036854775807 - 1  // i64::MIN
    let y = x / -1                          // traps: runtime error[E0603]
    print(y)
}
```

## How to fix
Check the magnitude of the operands before the operation, or restructure
the computation so intermediate values stay within the `i64` range. If you
genuinely need larger numbers, split the work so no single step overflows.
