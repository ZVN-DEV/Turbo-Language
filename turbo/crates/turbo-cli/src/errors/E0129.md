# E0129 — Cannot use ordering comparison on struct

## What it means
Ordering operators (`<`, `<=`, `>`, `>=`) are only defined on numeric
types. Struct values don't have an inherent ordering and can't be
compared this way.

## Example
```turbo
struct Point { x: i64, y: i64 }
fn main() {
    let a = Point { x: 1, y: 2 }
    let b = Point { x: 3, y: 4 }
    let lt = a < b  // no ordering on struct
}
```

## How to fix
Compare individual numeric fields, or implement your own comparison
helper function.
