# E0117 — While condition must be bool

## What it means
The condition of a `while` loop must be a boolean expression. Other
types (strings, structs, floats) are not accepted.

## Example
```turbo
fn main() {
    while "running" { break }  // str is not bool
}
```

## How to fix
Use a boolean expression, e.g. `while running == true` or maintain a
`bool` flag variable.
