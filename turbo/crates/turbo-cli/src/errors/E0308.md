# E0308 — Function already defined (duplicate)

## What it means
Two functions with the same name were defined in the same module.
Turbo does not support function overloading.

## Example
```turbo
fn greet() { print("hi") }
fn greet() { print("hello") }  // duplicate
```

## How to fix
Rename one of the functions, e.g. `greet` and `greet_formal`.
