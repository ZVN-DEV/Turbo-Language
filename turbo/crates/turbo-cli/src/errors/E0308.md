# E0308 — Duplicate definition

## What it means
The same name was defined twice where only one definition is allowed.
This covers two cases:

- **Duplicate function:** two functions with the same name in the same
  module. Turbo does not support function overloading.
- **Duplicate parameter:** two parameters with the same name in a single
  function's signature.

## Example
```turbo
fn greet() { print("hi") }
fn greet() { print("hello") }  // duplicate function

fn add(x: int, x: int) -> int {  // duplicate parameter `x`
    x + x
}
```

## How to fix
- For a duplicate function, rename one of them, e.g. `greet` and
  `greet_formal`.
- For a duplicate parameter, give each parameter a distinct name, e.g.
  `fn add(a: int, b: int)`.
