# E0116 — If condition must be bool

## What it means
The condition of an `if` expression must evaluate to a `bool` (or an
integer, which is treated as truthy/falsy). Strings, structs, and other
types are rejected.

## Example
```turbo
fn main() {
    if "yes" { print("ok") }  // str is not bool
}
```

## How to fix
Use a comparison like `if s == "yes"` or cast the value to a boolean
expression.
