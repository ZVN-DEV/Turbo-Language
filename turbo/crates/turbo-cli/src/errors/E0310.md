# E0310 — Method already defined (duplicate)

## What it means
Two methods with the same name were defined in the same `impl` block.

## Example
```turbo
struct Point { x: i64, y: i64 }
impl Point {
    fn area(&self) -> i64 { 0 }
    fn area(&self) -> i64 { 1 }  // duplicate
}
```

## How to fix
Rename one of the methods.
