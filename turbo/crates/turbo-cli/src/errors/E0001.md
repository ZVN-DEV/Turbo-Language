# E0001 — Unexpected token

## What it means
The parser encountered a token it did not expect at this position. This
usually means a typo, a missing operand, or a mismatched delimiter.

## Example
```turbo
fn main() {
    let x = +
}
```

## How to fix
Check for typos, missing operands, or mismatched delimiters near the
reported location. The span in the diagnostic points at the exact token
that derailed the parse.
