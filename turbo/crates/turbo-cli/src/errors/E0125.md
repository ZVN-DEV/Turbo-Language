# E0125 — Closure body type mismatch

## What it means
A closure's body expression produces a value whose type doesn't match
the closure's declared (or expected) return type.

## Example
```turbo
fn main() {
    let f: fn(i64) -> i64 = |x| "hello"  // str, not i64
}
```

## How to fix
Return a value whose type matches the closure's expected return type.
