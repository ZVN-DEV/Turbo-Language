# E0128 — Struct equality requires derive(Eq)

## What it means
Comparing two struct values with `==` or `!=` requires the struct to
have `#[derive(Eq)]` (or `derive(Eq)`) declared.

## Example
```turbo
struct Point { x: i64, y: i64 }
fn main() {
    let a = Point { x: 1, y: 2 }
    let b = Point { x: 1, y: 2 }
    let eq = a == b  // Point doesn't derive Eq
}
```

## How to fix
Add `derive(Eq)` to the struct definition:
`struct Point derive(Eq) { x: i64, y: i64 }`.
