# E0315 — Struct has no field

## What it means
A field access (`obj.field`) or struct literal (`Point { z: 1 }`) used
a field name that doesn't exist on the struct.

## Example
```turbo
struct Point { x: i64, y: i64 }
fn main() {
    let p = Point { x: 1, y: 2 }
    let z = p.z  // Point has no z
}
```

## How to fix
Check the struct definition for the correct field name, or add the
field if it's missing.
