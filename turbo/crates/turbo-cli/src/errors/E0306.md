# E0306 — Struct already defined (duplicate)

## What it means
Two structs with the same name were declared in the same module.
Struct names must be unique.

## Example
```turbo
struct Point { x: i64, y: i64 }
struct Point { a: i64 }  // duplicate
```

## How to fix
Rename one of the structs, or move them into separate modules.
