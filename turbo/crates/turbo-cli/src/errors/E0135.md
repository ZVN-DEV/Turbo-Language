# E0135 — Cannot access field on type

## What it means
You used dot-syntax (`x.field`) on a value whose type isn't a struct, or
on a struct that has no field by that name.

## Example
```turbo
fn main() {
    let x: i64 = 5
    let y = x.foo  // i64 has no fields
}
```

## How to fix
Ensure the receiver is a struct and the field exists. Double-check the
spelling and the struct definition.
