# E0602 — Index out of bounds

## What it means
An array or string was indexed at runtime with a position that does not
exist. For a value of length `n`, the valid indices are `0..n`
(0 through `n - 1`); anything outside that range traps and exits.

## Example
```turbo
fn main() {
    let arr = [1, 2, 3]
    print(arr[5])  // traps: runtime error[E0602], valid indices are 0..3
}
```

## How to fix
Check the index against the length before reading:
```turbo
fn main() {
    let arr = [1, 2, 3]
    let i = 5
    if i < len(arr) {
        print(arr[i])
    } else {
        print("index out of range")
    }
}
```
Remember ranges are half-open: an array of length `n` has no element at
index `n`. The same rule applies to string indexing (`char_at`).
