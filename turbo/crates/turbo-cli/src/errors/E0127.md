# E0127 — Unknown closure return type

## What it means
Turbo couldn't figure out what type the closure body returns. This
typically happens when the body uses values whose types are themselves
unresolved.

## Example
```turbo
fn main() {
    let f = || unknown_ident  // type unresolvable
}
```

## How to fix
Ensure all identifiers used in the closure body are defined with known
types, or add an explicit return type to the closure signature.
