# E0101 — Arithmetic on non-numeric type

## What it means
Arithmetic operators (`+`, `-`, `*`, `/`, `%`) require numeric operands:
`i8..i64`, `u8..u64`, `f32`, `f64`. The one exception is `+` on two
`str` values, which performs concatenation.

## Example
```turbo
fn main() {
    let x = true + 1  // bool is not numeric
}
```

## How to fix
Convert the value to a number first (e.g. `to_int(b)` if available), or
use an operation that makes sense for the type.
