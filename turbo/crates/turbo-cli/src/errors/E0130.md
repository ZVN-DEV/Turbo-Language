# E0130 — Incompatible compound assignment

## What it means
Compound assignment operators (`+=`, `-=`, `*=`, `/=`, `%=`) require the
right-hand side to have the same type as the target variable.

## Example
```turbo
fn main() {
    let mut x: i64 = 0
    x += "one"  // str is not i64
}
```

## How to fix
Use a value of the correct type on the right side of the compound
assignment.
