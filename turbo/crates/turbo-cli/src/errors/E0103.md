# E0103 — Cannot compare incompatible types

## What it means
Comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`) require both sides
to have compatible types.

## Example
```turbo
fn main() {
    let x = 42 == "hello"  // int vs str
}
```

## How to fix
Compare values of the same type. Convert one side if the comparison
semantically makes sense, or rethink the logic.
