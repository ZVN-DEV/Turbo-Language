# E0509 — Trait method not implemented

## What it means
An `impl Trait for Type` block is missing one or more methods required
by the trait.

## Example
```turbo
trait Display { fn show(&self) -> str }
struct Point { x: i64, y: i64 }
impl Display for Point {
    // missing show!
}
```

## How to fix
Implement every method required by the trait, matching the trait's
signatures exactly.
