# E0530 — Value is not callable

## What it means
You tried to call a value that is not a function, or you called a
first-class function value with the wrong number of arguments (or an
argument of the wrong type). Function values — closures and named
functions used as values — have a fixed signature `fn(params) -> ret`;
the call must match it, and only `fn`-typed values can be called.

## Example
```turbo
struct Bag { n: i64 }

fn main() {
    let b = Bag { n: 5 }
    print(b.n(3))   // error: field `n` is `i64`, not a function
}
```

```turbo
fn make_adder(n: i64) -> fn(i64) -> i64 {
    |x: i64| -> i64 { x + n }
}

fn main() {
    print(make_adder(3)(4, 5))  // error: expected 1 argument, found 2
}
```

## How to fix
- Only call values whose type is `fn(...) -> ...` (a closure or a named
  function). If you meant to read a field, drop the call parentheses.
- Match the function value's arity and parameter types exactly. Check the
  declared signature of the closure or function you are invoking.
