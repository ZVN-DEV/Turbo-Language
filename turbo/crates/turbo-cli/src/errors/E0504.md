# E0504 — Test function has parameters

## What it means
Functions marked `#[test]` (or `test fn`) must take no parameters.
The test runner invokes them with no arguments.

## Example
```turbo
test fn my_test(x: i64) {  // params not allowed
    assert(x > 0)
}
```

## How to fix
Remove the parameters. Use local variables or helpers to set up test
data.
