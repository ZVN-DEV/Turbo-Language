# E0107 — If/else branches have different types

## What it means
When `if`/`else` is used as an expression (its value is assigned or
returned), both branches must produce the same type.

## Example
```turbo
fn main() {
    let x = if true { 1 } else { "two" }  // int vs str
}
```

## How to fix
Return values of the same type from both branches, or convert one side.
If you don't need the value, use the `if` as a statement (not assigned).
