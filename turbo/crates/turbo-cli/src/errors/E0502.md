# E0502 — Cannot assign to immutable field

## What it means
You attempted to assign to a field on a value that was bound
immutably. In Turbo, mutability is a property of the binding, not the
struct.

## Example
```turbo
struct Point { x: i64, y: i64 }
fn main() {
    let p = Point { x: 1, y: 2 }
    p.x = 3  // p is immutable
}
```

## How to fix
Declare the binding as mutable: `let mut p = Point { ... }`.
