# E0313 — Cannot redefine builtin function

## What it means
A user function was declared with the same name as a compiler
builtin (`print`, `len`, `push`, `assert`, etc.). Builtins are
reserved.

## Example
```turbo
fn print(s: str) { }  // shadows builtin print
```

## How to fix
Pick a different name for your function, e.g. `my_print` or `log`.
