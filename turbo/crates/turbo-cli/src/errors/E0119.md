# E0119 — Null coalesce requires optional type

## What it means
The left operand of `??` must be an optional type (`T?`). Using it on a
non-optional value is meaningless — there's nothing to fall back from.

## Example
```turbo
fn main() {
    let x: i64 = 5
    let y = x ?? 0  // x is not optional
}
```

## How to fix
Either remove the `??` operator, or change `x` to be an optional
(`let x: i64? = some(5)`).
