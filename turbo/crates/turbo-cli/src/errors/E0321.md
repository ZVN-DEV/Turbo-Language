# E0321 — Undefined tool function in agent

## What it means
An agent referenced a tool function by name, but no `tool fn` with that
name exists in scope.

## Example
```turbo
agent Bot { tools: [do_thing] }  // do_thing not defined
```

## How to fix
Define the function as `tool fn do_thing(...) { ... }`, or remove the
reference from the agent.
