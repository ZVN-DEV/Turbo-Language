# E0104 — Logical operator expects bool

## What it means
Logical operators `&&` and `||` require both operands to be `bool`.

## Example
```turbo
fn main() {
    let x = 1 && 2  // ints are not bools
}
```

## How to fix
Replace the operands with boolean expressions, or use explicit
comparisons like `x != 0 && y != 0`.
