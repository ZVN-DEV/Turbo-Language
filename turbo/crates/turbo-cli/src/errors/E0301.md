# E0301 — Undefined function

## What it means
A function was called by name, but no function with that name is in
scope — not in the current module, not imported, and not a builtin.

## Example
```turbo
fn main() {
    do_stuff()  // no such function
}
```

## How to fix
Check for typos, import the module that defines the function, or
define it yourself.
