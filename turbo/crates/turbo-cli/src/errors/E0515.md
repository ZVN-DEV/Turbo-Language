# E0515 — Unused variable

## What it means
A local variable was declared with `let` but never read. This is
usually a sign of a typo or leftover code from an earlier revision.

## Example
```turbo
fn main() {
    let x = compute()  // x is never used
    print("done")
}
```

## How to fix
Remove the declaration, actually use the variable, or prefix the
name with an underscore (`let _x = ...`) to signal intentional
non-use.
