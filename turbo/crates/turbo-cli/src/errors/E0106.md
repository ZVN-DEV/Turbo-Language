# E0106 — Cannot apply logical not to non-bool

## What it means
The logical-not operator `!` only applies to `bool` values.

## Example
```turbo
fn main() {
    let x = !42  // cannot negate int
}
```

## How to fix
Use `!` on a boolean expression. If you need bitwise-not, use `~`
(where supported) or rewrite the logic with explicit comparisons.
