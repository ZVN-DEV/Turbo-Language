# E0200 — Match is not exhaustive

## What it means
A `match` expression must cover every possible value of the scrutinee's
type. For enums, every variant needs an arm (or you need a wildcard
`_` arm).

## Example
```turbo
enum Color { Red, Green, Blue }
fn name(c: Color) -> str {
    match c {
        Color::Red => "red"
        Color::Green => "green"
        // Blue is missing!
    }
}
```

## How to fix
Add the missing variants, or add a catch-all arm:
`_ => "other"`.
