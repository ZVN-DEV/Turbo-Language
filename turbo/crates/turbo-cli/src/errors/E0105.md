# E0105 — Cannot negate non-numeric type

## What it means
The unary `-` operator only works on numeric types (`i8..i64`, `u8..u64`
(signed only), `f32`, `f64`). Applying it to booleans, strings, or
structs is not allowed.

## Example
```turbo
fn main() {
    let x = -"hello"  // cannot negate str
}
```

## How to fix
Use `-` only on numeric values. For booleans, use `!` instead.
