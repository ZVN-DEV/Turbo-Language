# E0110 — Type annotation doesn't match value

## What it means
A `let` binding's explicit type annotation doesn't match the type of the
value on the right-hand side.

## Example
```turbo
fn main() {
    let x: i32 = "hello"  // annotation i32, value str
}
```

## How to fix
Either remove the annotation (so the type is inferred) or change the
value to match the annotation.
