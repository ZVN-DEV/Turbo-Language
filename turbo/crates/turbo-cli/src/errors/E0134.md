# E0134 — Cannot call method on type

## What it means
You called a method with dot-syntax (`x.foo()`) on a type that has no
method by that name. This includes calling struct methods on primitives
or mis-spelling a method name.

## Example
```turbo
fn main() {
    let x: i64 = 5
    x.do_something()  // i64 has no method
}
```

## How to fix
Check the type of the receiver and verify the method exists in an
`impl` block for that type. A typo is the most common cause.
