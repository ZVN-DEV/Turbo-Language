# E0137 — Unsupported compound assignment operator

## What it means
A compound assignment operator was used in a position where Turbo
doesn't currently support it, or the operator itself isn't implemented
for the operand types.

## Example
```turbo
fn main() {
    let mut s = "hi"
    s += "!"  // str += not supported
}
```

## How to fix
Use a plain assignment with an explicit expression (`s = s + "!"`) or
pick a supported operator.
