# E0126 — Cannot infer closure parameter type

## What it means
A closure parameter has no type annotation, and Turbo couldn't infer it
from the surrounding context (e.g. it wasn't assigned to a typed
variable or passed to a typed argument).

## Example
```turbo
fn main() {
    let f = |x| x + 1  // what type is x?
}
```

## How to fix
Add a parameter type annotation: `|x: i64| x + 1`, or assign the closure
to a variable with an explicit function type.
