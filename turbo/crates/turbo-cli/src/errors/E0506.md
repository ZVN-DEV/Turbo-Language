# E0506 — Constant must be a literal value

## What it means
Top-level `const` declarations must be initialized with a literal
(integer, float, string, bool) or a constant expression — not with a
function call or variable.

## Example
```turbo
fn compute() -> i64 { 42 }
const X: i64 = compute()  // not a literal
```

## How to fix
Use a literal value, or perform the computation once inside `main` and
store it in a local variable.
