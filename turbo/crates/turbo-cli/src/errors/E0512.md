# E0512 — Only named function calls supported

## What it means
Turbo currently only supports calling functions by name. Indirect
calls through function pointers stored in variables aren't fully
supported in every context.

## Example
```turbo
fn f() { }
fn main() {
    let g = f
    g()  // indirect call through variable
}
```

## How to fix
Call the function directly by name. Closures (with `|args| body`
syntax) work as first-class values in most situations.
