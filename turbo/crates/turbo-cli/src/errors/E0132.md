# E0132 — Pattern type incompatible with subject

## What it means
A pattern in a `match` arm has a type that can never match the subject
expression's type. For example, matching an integer literal against a
string value.

## Example
```turbo
fn main() {
    let x: i64 = 5
    match x {
        "hello" => print("no")  // str pattern, i64 subject
        _ => print("ok")
    }
}
```

## How to fix
Use patterns whose type matches the subject, or change the subject's
type.
