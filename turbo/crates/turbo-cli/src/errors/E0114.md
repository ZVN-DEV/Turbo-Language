# E0114 — Array elements must have the same type

## What it means
Every element in an array literal must have the same type. Turbo arrays
are homogeneous.

## Example
```turbo
fn main() {
    let xs = [1, "two", 3]  // mixed int and str
}
```

## How to fix
Use a single element type. If you need heterogeneous data, model it with
a struct or enum.
