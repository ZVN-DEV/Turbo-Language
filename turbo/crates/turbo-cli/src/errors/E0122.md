# E0122 — Range bounds must be integer

## What it means
Range expressions (`a..b`) used in `for` loops or as slice bounds
require integer operands on both sides.

## Example
```turbo
fn main() {
    for i in 0.0..10.0 { }  // floats, not ints
}
```

## How to fix
Use integer literals or integer-typed variables as range bounds.
