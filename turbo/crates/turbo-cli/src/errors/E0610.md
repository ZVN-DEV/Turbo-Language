# E0610 — Import could not be resolved

## What it means
An `import` statement referenced a file that the compiler could not load.
The path may be misspelled, point at a file that does not exist, sit in a
different directory than expected, or contain its own syntax errors. A
circular import (two files importing each other) also surfaces here.

## Example
```turbo
import { add } from "math.tb"  // no such file next to this source

fn main() {
    print(add(1, 2))
}
```

## How to fix
Import paths are resolved relative to the importing file's directory.
Check that:
- the file exists and the path is spelled correctly,
- the path is relative to the current file (e.g. `"./lib/math.tb"`),
- the imported file itself lexes and parses cleanly,
- there is no import cycle between the two files.
