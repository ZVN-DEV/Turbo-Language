# E0118 — Null coalesce type mismatch

## What it means
The null-coalesce operator `??` requires that the fallback value has the
same type as the inner type of the optional on the left side.

## Example
```turbo
fn main() {
    let x: i64? = none
    let y = x ?? "zero"  // inner type is i64, fallback is str
}
```

## How to fix
Make the fallback expression's type match the optional's inner type.
