# E0102 — Mismatched types in arithmetic

## What it means
Both sides of an arithmetic operation must have the same type. Turbo does
not implicitly widen between integer sizes or between signed and unsigned.

## Example
```turbo
fn main() {
    let x: i32 = 10
    let y: i64 = 20
    let z = x + y  // i32 + i64 mismatch
}
```

## How to fix
Ensure both operands are the same numeric type. If one is a literal,
giving the other an explicit type annotation is often enough.
