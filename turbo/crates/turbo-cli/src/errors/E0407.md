# E0407 — JIT finalization failed

## What it means
Turbo generated JIT code, but Cranelift could not finalize the compiled
definitions into executable memory. This usually means a compiled function
references a symbol that could not be resolved, or the backend rejected the
finished module.

## How to fix
Check the error message for the unresolved symbol or backend failure. If the
source program only uses normal Turbo code and builtins, please file an issue
with the source file that triggered the error.
