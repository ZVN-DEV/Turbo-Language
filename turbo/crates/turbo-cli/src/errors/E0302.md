# E0302 — Undefined struct

## What it means
A struct was referenced in a type position, literal, or pattern, but no
struct by that name has been defined in scope.

## Example
```turbo
fn main() {
    let p = Point { x: 1, y: 2 }  // Point not defined
}
```

## How to fix
Define the struct (`struct Point { x: i64, y: i64 }`) before using it,
or import it from the module that defines it.
