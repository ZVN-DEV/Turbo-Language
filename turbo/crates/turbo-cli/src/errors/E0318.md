# E0318 — Missing field in struct literal

## What it means
A struct literal omitted one or more required fields. Turbo requires
every field to be initialized when constructing a struct.

## Example
```turbo
struct Point { x: i64, y: i64 }
fn main() {
    let p = Point { x: 1 }  // missing y
}
```

## How to fix
Provide a value for every field: `Point { x: 1, y: 0 }`.
