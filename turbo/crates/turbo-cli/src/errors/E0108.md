# E0108 — Match arms have different types

## What it means
All arms of a `match` expression must produce the same type when the
match is used as an expression.

## Example
```turbo
fn main() {
    let x = 1
    let y = match x {
        1 => "one"
        _ => 42  // str vs int
    }
}
```

## How to fix
Return values of the same type from every arm, or use the match as a
statement (not assigned to anything).
