# E0510 — Trait impl return type mismatch

## What it means
A trait method was implemented with a return type that doesn't match
the trait's declared return type.

## Example
```turbo
trait Display { fn show(&self) -> str }
impl Display for Point {
    fn show(&self) -> i64 { 42 }  // expected str
}
```

## How to fix
Make the impl method's return type match the trait method's signature.
