# E0601 — Division by zero

## What it means
A division (`/`) or modulo (`%`) was evaluated at runtime with a divisor
of zero. Integer division by zero has no defined result, so the program
traps and exits instead of producing a garbage value.

## Example
```turbo
fn main() {
    let a = 1
    let b = 0
    print(a / b)  // traps: runtime error[E0601]
}
```

## How to fix
Guard the divisor before dividing:
```turbo
fn main() {
    let a = 1
    let b = 0
    if b != 0 {
        print(a / b)
    } else {
        print("cannot divide by zero")
    }
}
```
If a fallible result is more natural, return a `Result` (`a ! str`) from a
helper and surface the error to the caller instead of trapping.
